# UPSC Board Profiler

A free, static website for UPSC Civil Services interview (Personality Test) preparation.

- **Prepare:** enter your DAF details to see common questions and real questions asked to candidates with similar DAFs, by DAF area and by board.
- **Board library:** profiles of the current UPSC interview boards, with each member's career and questioning pattern.
- **Transcripts:** a searchable archive of about 2,700 interview transcripts from CSE 2020–2025.

Everything runs in the browser; there is no backend and nothing is uploaded.

Transcripts were shared by candidates and compiled by Team PTT (CSE 2020–2023), Team @csetranscripts (CSE 2024) and the Interview Transcripts (CSPT-2026) Telegram channel (CSE 2025). Names and contact details have been removed. Not affiliated with UPSC.

## Deploy
Static site: `index.html` plus the `data/` folder. On Vercel, import this repository with the framework preset "Other" and no build command.
